| [what-it-cannot-do.md](what-it-cannot-do.md) | something you expected is missing, and you need the verified answer plus the workaround |

| [vs-meta-official.md](vs-meta-official.md) | you are choosing between this server and Meta's own Ads MCP, or someone asks you to justify the choice |
