Open this section when something is wrong, or when an account you did not build has just landed on your desk.

| File | Use this when… |
|---|---|
| [account-audit.md](account-audit.md) | You inherited the account and need to know what is in it and where the money is going |

| [creative-teardown.md](creative-teardown.md) | One ad is doing all the work and you need to know which part of it does the work |
| [audience-audit.md](audience-audit.md) | You want to know who converts and who burns budget — age, gender, device, country, and all nineteen placement rows |

| [why-delivery-stopped.md](why-delivery-stopped.md) | A campaign is live but spending nothing, and you need to find out why |

**Skill:** [skills/meta-conversion-audit/SKILL.md](skills/meta-conversion-audit/SKILL.md) — loads the "conversions" field trap automatically.

Two things bite in almost every audit, so they are stated once and linked from everywhere else:

- **The number labelled "conversions" is not conversions.** [conversion-tracking-audit.md](conversion-tracking-audit.md) has the proven side-by-side.
- **The budget fields cannot tell you how much is left.** [budget pacing](../reporting/budget-pacing.md) explains what they actually report.
